One seat per company. A jury of three checkpoints from the same family is one model with a stutter, so a company already seated does not appear in the other menus.

Audit some code

Pick a folder. Everything in it is read on this machine, packed into one message, and sent to the model you choose — the same as pasting it in, just without the pasting. Nothing is changed, nothing is run.

OpenRouter API key

Saved to a 0600 file in ~/.board-of-directors on this machine. It goes to OpenRouter and nowhere else — the browser never receives it back. Get one at openrouter.ai/keys.

Saving checks the key with OpenRouter first, so you find out here rather than on your first question — including how many free requests a day this account gets, which OpenRouter reports and you should not have to know.

Only if OpenRouter will not say: has this account ever had $10+ of credits put in?

Exact usage — optional

An ordinary key cannot see its own usage, so the meter counts our calls and says estimated. A management key can read OpenRouter's own analytics and make it exact. Separate credential, from openrouter.ai/settings/management-keys.

It cannot make completions — but it can create and delete your API keys. This program only ever sends it to the analytics endpoint, and only to read. Leave it blank if you would rather not.
